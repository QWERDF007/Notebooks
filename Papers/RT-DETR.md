# [DETRs Beat YOLOs on Real-time Object Detection](https://arxiv.org/abs/2304.08069)

由于在速度和精度之间取得了合理的平衡，YOLO 系列已成为最流行的实时目标检测框架。然而，我们观察到 YOLO 的速度和精度受到 NMS 的负面影响。最近，基于端到端 Transformer 的检测器（DETRs）提供了一种消除 NMS 的替代方案。然而，高昂的计算成本限制了其实用性，并阻碍了其充分利用消除 NMS 的优势。在本文中，我们提出了实时检测 Transformer（RT-DETR），这是据我们所知第一个解决上述困境的实时端到端目标检测器。我们借鉴先进的 DETR，分两步构建 RT-DETR：首先我们在保持精度的同时提升速度，随后在保持速度的同时提升精度。具体而言，我们设计了一个高效的混合编码器，通过解耦尺度内交互和跨尺度融合来快速处理多尺度特征，从而提升速度。然后，我们提出了最小不确定性查询选择，为解码器提供高质量的初始查询，从而提升精度。此外，RT-DETR 支持通过调整解码器层数来灵活调整速度，从而在无需重新训练的情况下适应各种场景。我们的 RT-DETR-R50 / R101 在COCO上达到了 53.1% / 54.3% 的 AP，在 T4 GPU 上达到了 108 / 74 FPS，在速度和精度上均优于此前先进的 YOLO 模型。此外，RT-DETR-R50 在精度上比 DINO-R50 高出 2.2% AP，在 FPS 上快约 21 倍。在使用 Objects365 预训练后，RT-DETR-R50 / R101 达到了 55.3% / 56.2% 的AP。项目主页：[https://zhao-yian.github.io/RTDETR](https://zhao-yian.github.io/RTDETR/)

## 1. Introduction

实时目标检测是一个重要的研究领域，具有广泛的应用，如目标跟踪[43]、视频监控[28]和自动驾驶[2]等。现有的实时检测器通常采用基于 CNN 的架构，其中最著名的是 YOLO 系列检测器[1, 10–12, 15, 16, 25, 30, 38, 40]，因为它们在速度和精度之间取得了合理的平衡。然而，这些检测器通常需要非极大值抑制（NMS）进行后处理，这不仅拖慢了推理速度，而且引入了导致速度和精度不稳定的超参数。此外，考虑到不同场景对召回率和精度的侧重点不同，必须仔细选择合适的 NMS 阈值，这阻碍了实时检测器的发展。

最近，基于 Transformer 的端到端检测器（DETRs）[4, 17, 23, 27, 36, 39, 44, 45] 因其精简的架构并消除了手工设计的组件，受到了学术界的广泛关注。然而，其高昂的计算成本使其无法满足实时检测的要求，因此无 NMS 的架构并未展现出推理速度上的优势。这启发我们探索是否可以将 DETRs 扩展到实时场景，并在速度和精度上超越先进的 YOLO 检测器，从而消除实时目标检测中由 NMS 带来的延迟。

为了实现上述目标，我们重新审视了 DETRs 并对关键组件进行了详细分析，以减少不必要的计算冗余并进一步提高精度。针对前者，我们观察到尽管引入多尺度特征有助于加速训练收敛[45]，但这会导致馈入编码器的序列长度显著增加。由多尺度特征交互引发的高计算成本使得 Transformer 编码器成为了计算瓶颈。因此，实现实时 DETR 需要重新设计编码器。针对后者，以往的研究[42, 44, 45]表明，难以优化的目标查询（object queries）阻碍了 DETRs 的性能，并提出了查询选择（query selection）方案，用编码器特征替换原始的可学习嵌入（learnable embeddings）。然而，我们观察到当前的查询选择直接采用分类分数进行挑选，忽略了检测器需要同时对目标的类别和位置进行建模的事实，而这两者共同决定了特征的质量。这不可避免地导致定位置信度较低的编码器特征被选作初始查询，从而引发相当程度的不确定性并损害 DETRs 的性能。我们将查询初始化视为进一步提升性能的突破口。

在本文中，我们提出了实时检测 Transformer（RT-DETR），据我们所知，这是首个实时端到端目标检测器。为了快速处理多尺度特征，我们设计了一种高效的混合编码器来替代原始的 Transformer 编码器，该编码器通过解耦不同尺度特征的尺度内交互与跨尺度融合，显著提高了推理速度。为了避免将定位置信度低的编码器特征选作目标查询，我们提出了不确定性最小化查询选择，通过显式地优化不确定性，为解码器提供高质量的初始查询，从而提高精度。此外，得益于 DETR 的多层解码器架构，RT-DETR 支持灵活的速度调节，无需重新训练即可适应各种实时场景。

RT-DETR 在速度和精度之间实现了理想的平衡。具体而言，RT-DETR-R50 在 COCO val2017 上实现了 53.1% 的 AP，在 T4 GPU 上达到 108 FPS；而 RT-DETR-R101 实现了 54.3% 的 AP 和 74 FPS，在速度和精度上均超越了以往先进 YOLO 检测器的 L 和 X 模型，如图 1 所示。我们还通过使用较小的骨干网络（backbones）缩放编码器和解码器，开发了缩放版的 RT-DETRs，其性能优于更轻量的 YOLO 检测器（S 和 M 模型）。此外，RT-DETR-R50 在精度上超越了DINO-Deformable-DETR-R50 2.2% 的 AP（53.1% AP vs 50.9% AP），在 FPS 上快了约 21 倍（108 FPS vs 5 FPS），显著提升了 DETRs 的精度和速度。在使用Objects365[35] 进行预训练后，RT-DETR-R50 / R101 实现了 55.3% / 56.2% 的AP，带来了令人惊叹的性能提升。更多实验结果在附录中提供。

主要贡献总结如下：(i). 我们提出了首个名为 RT-DETR 的实时端到端目标检测器，它不仅在速度和精度上超越了以往先进的 YOLO 检测器，而且消除了由 NMS 后处理对实时目标检测造成的负面影响；(ii). 我们定量分析了 NMS 对 YOLO 检测器速度和精度的影响，并建立了一个端到端速度基准，以测试实时检测器的端到端推理速度；(iii). 所提出的 RT-DETR 支持通过调整解码器层数进行灵活的速度调节，在无需重新训练的情况下适应各种场景。

# [AMES: Asymmetric and Memory-Efficient Similarity Estimation for Instance-level Retrieval](https://arxiv.org/abs/2408.03282)

本研究探讨了在内存效率约束下的实例级图像检索重排序问题，最终目标是将每张图像的内存使用限制在 1KB 以内。与以往主要关注性能提升的研究不同，本文优先考虑性能与内存需求之间的关键权衡。所提出的模型采用基于 Transformer 的架构，通过捕捉图像内部及跨图像的局部描述子之间的交互关系，来估计图像间的相似性。该模型的一个显著特性是具备非对称相似性估计能力。与查询图像相比，数据库图像使用更少数量的描述子进行表示，从而在不增加内存消耗的前提下提升了性能。为了确保模型在不同应用场景中的适应性，我们还引入了一个通用模型，可在测试阶段灵活应对不同数量的局部描述子。在多个标准基准数据集上的实验结果表明，我们的方法在性能上优于手工设计的模型和基于学习的模型。特别是与当前最先进的、忽视内存占用的方法相比，我们的方法不仅实现了更优的性能，同时显著减少了内存开销。代码和预训练模型已公开发布于：https://github.com/pavelsuma/ames

## 1 Introduction

图像检索方法通常专注于优化性能指标，并且由于现代特征表示 [1, 5, 13, 43] 的发展，已经在很多情况下取得了显著的效果提升。高维度的特征表示能够更好地估计图像之间的相似性，从而带来更好的检索精度 [34, 46]。然而，人们通常忽视的是存储这些表示所带来的内存占用问题。存储高维且通常是稠密的特征表示会占用大量内存，这使得它们难以应用于大规模的网络场景。因此，在追求性能的同时，也必须认真考虑其带来的内存开销。本研究正是聚焦于这一常常被忽视的双重因素。我们分析在实例级图像检索任务中性能与内存占用之间的权衡关系。具体来说，我们在同时使用局部描述子和全局描述子的前提下，对这种权衡关系进行研究并加以改进，理想情况下，这两种描述子都由一个通用模型 [8] 提供。

全局描述子因其计算和内存效率，在处理大规模数据库中的图像检索时提供了一种便捷的方式。它们不仅能够快速完成检索任务，还可以通过近似最近邻搜索技术 [4, 26] 进一步加速检索过程。同时，数据库图像特征的存储所需内存较少，而通过降维或其他压缩技术  [20, 24, 42] 还能进一步降低内存占用。尽管基于深度学习的全局描述子在多个基准测试中表现出色，但它们仍然存在一些缺点。尤其是在面对严重背景干扰的情况下，例如小物体识别或大范围遮挡 [17] 时，全局描述子的表现往往不尽人意。

一种提升性能的方法是使用一组局部描述子来表示图像，并采用相似度函数来比较两个局部描述子集。这种相似度函数可以是手工设计的 [44, 62]，也可以包含可学习的部分 [28, 61]。这类方法的一个重要方面是，局部描述子通常在重新排序阶段 [39, 61] 使用，即在更高效的初步排序阶段（例如使用全局描述子进行检索）之后。通过这种方式，使用局部描述子带来的高计算成本变得不那么显著，尤其是在需要重排序的图像数量有限的情况下。然而，它们较大的内存占用仍然是一个主要缺点。

我们探索并优化了检索性能与内存需求之间的权衡，特别是在每张图像仅占用低至 1KB 的低内存占用情况下，以实现可扩展的解决方案。我们的方法针对内存相关的两大主要因素进行了优化：操作时使用的局部描述子数量较少，每个描述子的内存占用较低。我们设计了一个用于捕捉图像内部及跨图像交互的图像间相似性模型，该模型使用了 Transformer 架构。这种权衡通过以下四种方式得到优化：(i) 非对称相似性估计——查询图像由较多数目的局部描述子表示，而不增加数据库的内存占用（如图1所示），(ii) 训练模型处理以端到端方式学习到的二进制输入向量，(iii) 通过知识蒸馏过程，其中教师模型使用的表示比学生模型更加丰富，(iv) 在重排序阶段适当结合全局和局部描述子给出的相似度。

在实际系统中，为了控制内存占用和检索速度，可能需要根据不同情况调整每个数据库或查询图像所使用的局部描述子数量。为了解决这一问题并构建一个适用于各种情况的通用模型，我们在训练过程中改变每张图像所使用的局部描述子数量。这种方法成功缓解了我们在实验中观察到的 Transformer 模型对输入 token 数量变化的敏感性问题——即当训练与测试阶段输入 token 数量不一致时，性能往往会下降。以下是本文的主要贡献概述：

- 我们首次系统地研究了在实例级图像检索任务中，深度模型及其特征表示在性能与内存消耗之间的权衡问题。
- 我们提出了 AMES，一种受现有技术启发的新型相似度估计架构和训练策略，并专门针对我们特定的需求和目标进行了优化。
- 我们揭示了 Transformer 架构对输入 token 数量变化的敏感性，并开发了一个通用模型，能够对此类变化保持鲁棒性，从而在不同运行条件下均能保持稳定的性能表现。

## 2 Related work

**使用全局描述子的相似性计算**。传统的图像检索方法通过聚合手工设计的局部特征来提取全局表示，例如 BoW [10, 53]、Fisher vectors [38, 48]、VLAD [19] 或三角化嵌入 [25]，并通过计算简单的度量（如余弦相似度）来进行检索。这些表示的内存占用进一步通过不同版本的 PCA [20, 42] 或乘积量化（PQ）[24] 来降低维度。随着深度网络的发展，利用学习到的（即非手工设计的）描述子已成为图像检索中的一种流行选择 [1, 33]。该领域的早期工作是使用为分类训练的神经网络，并通过聚合内部激活图将其应用于图像检索 [5, 43]。更新的方法则是直接训练专门用于图像检索的神经网络，通过优化不同的度量学习损失 [45, 50]、训练数据采样 [32, 54, 57, 68] 和架构设计 [55, 56] 来获取鲁棒的全局表示。在最近的工作中，SuperGlobal [51] 描述子通过重新调整已训练好的检索模型架构并经过适当的超参数调优后提取得到。除了全局描述子外，有些模型还通过独立的网络分支导出局部描述子 [8, 58, 72]。

**使用局部描述子的相似性计算**。与将局部表示聚合为全局表示相反，特定的度量被设计用于比较局部描述子并估计图像间的相似性。传统方法遵循 BoW 范式，但使用匹配核来计算分配给相同视觉单词的局部特征之间的相似性 [21, 62]。哈明嵌入 [21] 使用二进制编码以显著减少内存需求，因为其需要索引额外的特征。这些核可以与加权结合使用，以减少突发效应 [22] 或考虑嵌入空间中的局部密度 [2]。ASMK [62] 采取了一种中间路线，仅聚合属于同一视觉单词的局部特征，这减少了存储数据库特征的内存占用，而通过二值化进一步减少。研究表明，这些方法在性能上不如可学习的重排序方法 [61]，或者可以通过适当的表示学习来改进 [66]。

不同形式的几何约束被证明对图像相似性估计有帮助，例如空间邻域的一致性 [53]、角度和尺度的一致性 [23]，或相对空间顺序的一致性 [14, 71]。通过类似 RANSAC 的方法 [11] 进行几何验证是估计图像相似性的最常用手段之一，不仅适用于手工设计的局部描述子 [39, 40]，也广泛应用于从深度网络中提取的局部特征 [8, 35, 52]。这是一种耗时较长的重排序方法，由于需要存储局部特征的几何信息，还会带来额外的内存开销。

近年来深度学习的发展推动了基于局部描述子的图像间相似性估计模型的进步 [61, 73]。这些模型允许针对特定任务直接优化相似性计算，从而提升整体性能。RRT [61] 和 R2Former [73] 在性能和处理速度上优于传统的空间验证方法，但它们需要存储数百个全精度描述子。CVNet [28] 则使用一个四维卷积网络来处理密集特征图之间的跨尺度相关性，内存需求甚至更高。本文提出的模型借鉴了 RRT 架构的设计理念，并对其进行了有效的扩展。为了评估我们模型的性能，我们将其与 RRT、R2Former 和 CVNet 进行直接比较，结果显示我们的方法在性能和内存效率方面均具有优势。

此外，我们的架构设计还融合了图像匹配网络 [30, 49, 60] 的思想。这类方法利用自注意力和交叉注意力层的组合，促进单张图像内部以及两幅图像之间的信息交互。通过整合这些先进理念，我们的模型实现了更为高效的相似性估计方法。

**非对称相似性**被先前的研究用于优化性能与内存之间的权衡，其方法是通过将二值向量与全精度向量进行比较 [18]。这种思路与我们的工作具有互补性。最近，多种深度学习方法致力于优化性能与查询时间之间的权衡，例如通过轻量级的查询处理机制 [7, 59, 69] 或在数据库端使用模型集成 [70]。 而我们的通用模型则可以通过处理不同数量的查询局部描述子，灵活地控制查询时间。

**Transformer 对 token 集大小差异的敏感性**。在自然语言处理（NLP）中，诸如问答等任务在训练和测试阶段本质上会遇到长度变化较大的句子 [64]。 Transformer 模型通常对这种变化具有一定鲁棒性，除非在测试时遇到显著更长的句子 [9, 47]。受此启发，我们提出在训练过程中使用不同数量的输入 tokens 来提升模型的适应能力。类似的现象也在 Flexible Vision Transformers (ViTs) [6] 和 CAPE [29] 中被观察到，这些工作中考虑了图像块或图像尺寸的变化，这些变化会间接影响 token 集的大小。

## 3 Method for memory-efficient similarity estimation

我们首先介绍内存高效检索的任务，然后提出一种方法，用于训练一个图像到图像的相似性模型，该模型以两组局部描述子作为输入，同时保持较低的内存占用。

### 3.1 Problem formulation

图像检索的目标是使用给定的查询图像 $q$ 在图像数据库 $\mathcal{X}$ 中进行搜索，并检索相关的图像。在本工作中，我们将“相关性”定义为描绘同一个特定对象的情况，侧重于实例级检索。查询图像与数据库中某图像 $x \in \mathcal{X}$ 之间的图像相似性由函数 $s(x,q) \in \mathbb{R}$ 来度量。随后，根据该相似性得分对结果进行排序，生成数据库图像的排序。

与大多数以往主要强调性能指标的研究不同，我们认为一个图像检索方法的优劣应综合考虑性能表现与内存占用。其中，内存占用指的是存储用于相似性估计的图像表示（即特征）所需的内存空间。查询的内存分配不太重要，因为它在检索过程结束时会被释放。因此，我们在本研究中探索并认可了非对称设置的价值。

### 3.2 Preliminaries

单一向量图像表示，称为全局描述子，是一种内存和计算效率都很高的相似性计算方法。数据库图像 $x$ 和查询图像 $q$ 的 $\ell_2$ 归一化全局描述子分别表示为 $\mathbf{x} \in \mathbb{R}^{d_g}$ 和 $\mathbf{q} \in \mathbb{R}^{d_g}$ 。图像相似性则简化为点积形式 $s_g(x,q) = \mathbf{x}^{\top} \mathbf{q}$ ，这也被称为全局相似性。

为了提升检索质量，一种常见的做法是使用多个向量（如局部描述子）来表示每张图像。这样，每个数据库图像 $x$ 就可以通过 $X \in \mathbb{R}^{D \times L_x}$ 中的 $L_x$ 个 D 维向量来表示，而查询图像 $q$ 则通过 $Q \in \mathbb{R}^{D \times L_q}$ 中的 $L_q$ 个向量表示。尽管在处理无序向量集，我们采用了矩阵表示法以求清晰表达。图像间的相似性定义为 $s_l(x,q) = S(X,Q)$ ，这被称为局部相似性，其中 $S: \mathbb{R}^{D \times L_x} \times \mathbb{R}^{D \times L_q}$ 是一个作用于两个向量集上的相似度函数。这两个集合的大小不需要相同。虽然设计和实现 $S$ 的选项多种多样，但与全局相似性估计相比，其计算复杂度不可避免地更高。一种实际的解决方案是在初始排序阶段估计全局相似性，在根据第一步重新排序最相似的图像时再计算局部相似性。然而，这种方法需要存储图像 $x$ 的全局和局部表示。根据 $d_g, D, L_x$ 的值，对于大型数据库而言，这种方法可能很快变得不切实际。因此，保持较低的内存占用至关重要。

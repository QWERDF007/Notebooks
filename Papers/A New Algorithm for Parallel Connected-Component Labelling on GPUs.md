# A New Algorithm for Parallel Connected-Component Labelling on GPUs

## Abstract

连通域标记仍然是处理和分析图像以及各种应用领域中其他形式数据的重要且广泛使用的技术。不同的数据源会生成具有不同结构特征的组件，并且可能或多或少适合某些连通域标记算法。尽管存在许多高效的串行算法，但在图形处理单元 (GPU) 上确定连通域引起了人们的兴趣，因为许多应用程序使用 GPU 来处理应用程序的其他部分，在 GPU 上进行标记可以避免昂贵的内存传输。本文讨论了连通域标记的一般问题，并讨论了两种现有的基于 GPU 的算法——标签等价法和 Komura 等价法。提出了一种新的基于 GPU 的并行的连通域标记算法，该算法识别并消除了先前方法中用于直线型二维和三维数据集的冗余操作。文中提出了一组具有一系列结构特征和系统大小的测试用例，并用于评估在现代 NVIDIA GPU 设备上的新标记算法，并将其与现有算法进行比较。性能评估结果表明，在各种测试用例中，新算法可以比以前的方法提供显著的性能改进。代码：https://github.com/FolkeV/CUDA_CCL

## 1 INTRODUCTION

连通区域标记（CCL）算法在许多应用中扮演着重要角色，尤其是在模式分析和图像处理领域。连通区域标记问题的核心是在数据集中为每个连通区域内的元素分配唯一的标签。该问题通常可以当作一个节点图，但在许多实际应用中，数据集往往具有规则结构，例如图像和体素数据。

随着硬件的发展推动处理器架构日益并行化，人们对开发用于解决常见问题的并行算法的兴趣也在增加。图形处理器（GPU）因其适用于高吞吐量计算任务，已成为一种常见的计算架构。许多图像处理方法可以在 GPU 上轻松实现并获得良好的性能；但对于像 CCL 这样结构较不规则的问题，其性能往往较低。然而，对于某些应用来说，即使 GPU 算法的性能能够与 CPU 算法相当也已足够，因为这样可以避免设备与主机之间的数据传输，使整个应用程序能够在 GPU 上完成计算 [1]。

已有多种用于在图形处理器上执行连通区域标记的算法被提出，适用于不同的应用场景。相关研究包括：基于块-游程（Block-Run）的算法 [2]、滑动窗口方法 [3]、并查集（Union-Find）算法 [4],[5]、基于行的算法 [6]、预轮廓提取（Pre-Contouring）[7]、Voronoi 图的扩展应用 [8] 以及三维连通区域标记 [9]。其他相关研究还包括面向现场可编程门阵列（FPGA）的算法实现 [10], [11], [12]。这些算法和实现方式通常专注于特定情况或特定的数据模式。

连通区域标记算法本身具有广泛的应用，包括但不限于：目标检测（如河流检测 [13]）、轮廓提取 [14]、文档修复 [15]、最小矩形检测 [16]、对象跟踪 [17]、图像分割 [18], [19], [20]、图分析 [21], [22], [23], [24], [25]、路径不存在性证明 [26]、医学影像应用 [1], [27]、基于聚类的物理模型更新和分析 [28], [29], [30], [31], [32], [33] 以及自组织 [34]。
